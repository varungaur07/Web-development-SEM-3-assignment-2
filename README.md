# Web Development SEM-3 - Assignment 2

Student API project built with Node.js & Express.

### What I did
- Created a REST API for students
- Made custom logger middleware
- Used modular structure (routes, middleware, data)

### Routes
- `GET /` - Home
- `GET /students` - Get all students data

### How to run
npm install
node app.js

Open: http://localhost:3000

### Tech Used
Node.js, Express.js
